# Glossary

| Term | Meaning in this project |
| --- | --- |
| **Listing** | An item a member offers: sell, rent, lend or give away. Table `listings`; expires after 30 days |
| **Need** | A request posted by a member who is looking for an item (buy, rent or borrow). Table `needs` |
| **Interest** | A buyer's request on a listing, optionally with a message. Table `interests`; `PENDING → ACCEPTED/REJECTED` |
| **Contact reveal** | Fetching the counterparty's name, email and phone via `GET /interests/{id}/contact`, allowed only after acceptance |
| **Trainee community** | Infosys Mysore trainees – the audience for the marketplace |
| **SE / DSE / SP_L1 / SP_L2** | The `UserRole` values chosen at registration (the role/designation of the member) |
| **Admin** | A user with `is_admin = true`; can open `/admin` and call `/api/admin/*` |
| **Deactivated user** | `is_active = false`; all protected calls return `403` |
| **Audit log** | `audit_logs` rows recording privileged admin actions |
| **Request ID** | Correlation ID (`X-Request-ID`) attached to each request/response and every log line |
| **Pooled / unpooled URL** | Neon's pgbouncer-backed connection (`DATABASE_URL`, runtime) vs the direct connection (`DATABASE_URL_UNPOOLED`, migrations) |
| **Advisory lock** | PostgreSQL lock `pg_advisory_xact_lock(74193820416)` that makes concurrent startup migrations run one at a time |
| **WIF** | Workload Identity Federation – GitHub OIDC → Google Cloud auth without service-account keys |
| **SBOM** | Software bill of materials; a CycloneDX file is generated and retained per release image |
| **Digest deploy** | Deploying the container by immutable `sha256:` digest rather than a tag, so the scanned image is exactly what runs |
| **`neon-staging`** | The GitHub environment that gates the Cloud Run deployment (reviewers/branch restriction configured in GitHub) |
| **Deploy branch** | `deploy/neon-cloudrun-cloudflare-pages` – the only branch whose pushes trigger deployments |
| **`_headers` / `_redirects`** | Cloudflare Pages files: response headers (generated by Vite) and the SPA fallback rule (`public/_redirects`) |
| **CSP report-only** | A Content-Security-Policy that logs violations in the browser console without blocking anything; the SPA's CSP is in this mode |
| **HSTS** | `Strict-Transport-Security` header; API sends it when `HSTS_ENABLED=true` |
| **PITR** | Point-in-time recovery (Neon feature, depends on plan) |
| **ZAP** | OWASP Zed Attack Proxy, used for dynamic scanning via `scripts/security/zap-api-scan.ps1` |
| **Magic bytes** | The leading bytes of a file that identify its real format; used to verify uploaded images |
